指の位置 自動調整（全曲）

曲ごとに、指が正しい鍵に届くよう鍵盤の位置・大きさと手の値を探します。1曲 1〜3 分ほど。
終わったら「song.json を書き出す」で曲ごとにダウンロード → songs/<id>/song.json に上書き。
URL パラメータ: ?vrm= VRM の URL（なければファイルを選ぶ）、&songsDir= 曲フォルダ、&songs=id1,id2 曲をしぼる、&auto=1 開くとすぐ始める（結果の保存は node tools/apply_fit.mjs）。
For each song, searches the keyboard position/scale and hand values so fingers land on the right keys. About 1–3 minutes per song.
When finished, "Export song.json" downloads one file per song → overwrite songs/<id>/song.json.
URL parameters: ?vrm= VRM URL (otherwise pick a file), &songsDir= songs folder, &songs=id1,id2 limit songs, &auto=1 start immediately (save results with node tools/apply_fit.mjs).

曲違う鍵浮き届かない左右高さ前後大きさ届き手首手前
